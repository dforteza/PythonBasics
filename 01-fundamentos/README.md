# 01 - Fundamentos de Python

*Conceptos básicos del lenguaje Python.*

## Estructura del directorio

```
01-fundamentos/
├── tipos_datos/                  # Apuntes y ejercicios sobre tipos de datos
│   ├── listas.py                 # Apuntes sobre listas
│   ├── diccs.py                  # Apuntes sobre diccionarios
│   └── ejercicios/               # Ejercicios prácticos con tipos de datos
└── lambdas/
    └── lambdas.py                # Funciones lambda y funciones de orden superior
```

## Contenido

- **`tipos_datos/`** - Apuntes y ejercicios sobre listas, diccionarios y otros tipos de datos
- **`lambdas/`** - Funciones lambda y funciones de orden superior
- **`tipos_datos/ejercicios/`** - Destacados: `Wordle.py` (juego) y `python_verifier.py` (verificador de sintaxis)

## Ejecutar

```bash
cd 01-fundamentos/tipos_datos
python listas.py
```
