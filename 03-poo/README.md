# 03 - Programación Orientada a Objetos

Conceptos de POO en Python basados en el paradigma orientado a objetos.

## Estructura del directorio

```
03-poo/
├── poo_aptes.py                     # Apuntes de POO con ejemplos prácticos
├── ejercicios/                      # Carpeta con ejercicios prácticos
│   ├── videogame_service.py         # Sistema de videojuegos (clases y objetos)
│   ├── biblioteca.py                # Sistema de biblioteca (métodos de clase)
│   ├── banco.py                     # Sistema bancario (herencia y polimorfismo)
│   ├── tienda_online.py             # Tienda online (encapsulación + dunder methods)
│   ├── zoologico.py                 # Zoológico (clases abstractas + herencia)
│   └── sistema_de_empleados.py      # Sistema de empleados (ejercicio integrador)
└── poo_orientada_a_huertos/         # Proyecto: Sistema de gestión de huertos
    ├── main.py                      # Implementación del sistema de huertos
    └── requirements.txt             # Dependencias del proyecto
```

## Contenido

- **`poo_aptes.py`** - Conceptos fundamentales de POO: clases, objetos, métodos de instancia/clase/estáticos, atributos
- **`ejercicios/`** - Ejercicios prácticos que cubren todos los aspectos de POO
- **`poo_orientada_a_huertos/`** - Proyecto completo simple aplicando POO a un sistema de gestión de huertos
