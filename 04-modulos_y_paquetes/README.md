# 04 - Módulos y Paquetes

Organización del código en módulos reutilizables y paquetes.

## Estructura del directorio

```
04-modulos_y_paquetes/
├── apuntes_modulos.py          # Apuntes y ejemplos de módulos y paquetes
├── entornos_virtuales.txt      # Guía sobre entornos virtuales en Python
├── mi_modulo.py                # Ejemplo de módulo personalizado
├── otro_modulo.py              # Otro ejemplo de módulo
└── mi_paquete/                 # Ejemplo de paquete Python
    ├── __init__.py             # Inicializador del paquete
    ├── matematicas.py          # Módulo de operaciones matemáticas
    └── utilidades.py           # Módulo de utilidades
```

## Contenido

- **`apuntes_modulos.py`** - Conceptos de importación, uso de `__name__`, `sys.path` y organización de código
- **`entornos_virtuales.txt`** - Documentación sobre creación y gestión de entornos virtuales
- **`mi_modulo.py`** y **`otro_modulo.py`** - Ejemplos prácticos de módulos
- **`mi_paquete/`** - Estructura de paquete Python con múltiples módulos
